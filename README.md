# MODA & CO. — Loja demonstrativa

Este site é uma demonstração de uma loja virtual de roupas. Ele apresenta uma vitrine de produtos fictícios para que você possa conhecer e testar a navegação e o carrinho.

## O que você pode testar

- Explorar os produtos e filtrar a vitrine por categoria.
- Adicionar peças ao carrinho e conferir a quantidade e o valor total.
- Preencher os dados de entrega no formulário de finalização.

## Importante

- Os produtos, imagens e preços são exemplos de demonstração e não representam necessariamente itens disponíveis para compra.
- O carrinho funciona somente nesta sessão do navegador. Os itens não são salvos nem compartilhados com a loja ou com outros visitantes; ao atualizar ou fechar a página, o carrinho é reiniciado.
- O site não processa pagamentos nem registra pedidos em um sistema.
- A finalização depende da configuração do número de WhatsApp da loja. Se não estiver configurado, o pedido não será enviado.
- Quando a finalização estiver configurada, os dados de entrega preenchidos serão incluídos na mensagem aberta no WhatsApp. Revise as informações antes de enviá-la.
- Use somente dados fictícios ao testar.
